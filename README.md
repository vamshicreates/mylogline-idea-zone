# Film Idea Zone for My Logline

A standalone, static editorial site for Indian real-life film ideas. The first release has **Biopic** and **Based on True Events** categories, four complete treatments, and three source links per story.

## Local preview

```bash
npm run check
npm run build
npm run dev
```

Open `http://127.0.0.1:4173/`. The site has no npm dependencies. `npm run dev` serves the built files; run `npm run build` again after changing a story.

## Edit stories

Edit [stories.mjs](./stories.mjs). Each story needs one of the two categories, `country: 'India'`, three research sources (two Wikipedia links and one corroborating link), a logline, synopsis, exactly 13 beats, an editorial note, and an image with attribution. Put image files in `images/`; the build copies them into `dist/images/`. `storyDna` in the same file holds the fresh angle, roles, story mechanics, and research gaps. `npm run check` validates the required shape.

The visual palette uses My Logline's live site colors: `#0F0F0F`, `#CE2827`, `#EFAAA9`, and `#F2F2F2`. Photo credits and licenses appear on every story page. The two historic originals are lower resolution than the modern portraits; their source quality is disclosed in the credits.

The source files are the deliverable. `dist/` is generated by the build command.

## Public deployment

[Film Idea Zone](https://mylogline-idea-zone.vercel.app) is deployed on Vercel from the `main` branch of [vamshicreates/mylogline-idea-zone](https://github.com/vamshicreates/mylogline-idea-zone). Its [vercel.json](./vercel.json) builds the site into `dist/`; future pushes to `main` deploy automatically. The main writing CTA goes to the existing My Logline login page.

The planned `ideazone.mylogline.com` domain and main-site navigation link are the next integration steps. When the custom domain is connected, update `base` in `build.mjs` for canonical URLs and the sitemap.
